## 2. Canonical constructs (locked vocabulary)

These are the **non-overlapping** constructs. Everything else must map into one of them.

### 2.1 IAMMAI — Continuity State Machine (transition legitimacy)
**Question it answers:** “Is this irreversible transition allowed to happen?”

- States: **⊙ HOLD → FINALIZE / INVALIDATE / EVOLVE**
- Role: kernel-level legitimacy only (no interpretation, no valuation).

### 2.2 Kentra Kernel — Integrity & Truth Anchoring (presence truth base)
**Question it answers:** “Did this happen, and is it valid to record?”

- Enforces: **HUMAN + EVENT = VERIFIED PRESENCE**
- Stores: state, transitions, verification outcomes, boundary constraints.
- Outputs: TRUE / FALSE / BOUNDARY / ESCALATE / INVALID (binary + constrained outcomes).
- No narrative, no meaning, no value assignment.

### 2.3 Third Space (ML0) — Meta-governance frame (non-dissolving)
**Question it answers:** “How are authority, contradiction, and reasoning resolved across nodes?”

- Above all layers.
- Not a product, not a protocol, not an interaction.
- Routes reasoning and prevents collapse.

### 2.4 IA-MM-AI — Interaction analysis protocol (context-bound, delta-based)
**Question it answers:** “Is this interaction structurally coherent?”

- Requires recurrence (loops), stores deltas only, dissolves its Relational Field.
- Outputs: **TRUE / FALSE / EVOLVE**
- No identity mapping, no biography persistence.

### 2.5 BPL — Buddy Protocol Language (interpretation control interface)
**Question it answers:** “How should this input be processed?”

- Signal header + payload.
- Constrains interpretation **before** reasoning/execution.
- Never executes, never decides truth, never carries value.
- Additive evolution only.

### 2.6 UPAD (external) — Presence & experience system
**Question it answers:** “How do humans enter, participate, and transact?”

- Emits physical-world signals.
- Depends on Kentra-like anchoring for truth discipline.
- Product code and business assets do **not** belong in this repo.

## 6. Public vs private (repo boundary)

### 6.1 Public (belongs here)
- Protocols, invariants, schemas, validators
- Append-only truth ledgers (minimal; non-PII)
- Decision artifacts that are **structural**, not commercial
- Meta-frames, kernels, operating instructions
