0. PURPOSE

EVENT defines where and when truth may occur.

It answers one question only:
Within which bounded context does reality take place and then close?

EVENT is not a product.
EVENT is not a ticket.
EVENT is not a schedule.

EVENT is a truth container.

⸻

1. NON-NEGOTIABLE INVARIANTS
	1.	Every PoP belongs to exactly one EVENT.
	2.	EVENT is bounded in time.
	3.	EVENT closes exactly once.
	4.	EVENT closure is irreversible.
	5.	EVENT stores no identity.
	6.	EVENT does not carry or compute value.

⸻

2. CANONICAL STATES

EVENT has exactly three lifecycle states:

• 0 — Pre-Event
• ⊙ — Live (KAPIA-enabled)
• 1 — Closed

States are not optional.
States are not reorderable.

⸻

3. CORE DEFINITIONS

Event Context:
A bounded container in which potential may collapse into reality.

Closure:
The irreversible act that freezes the event’s truth scope.

Event Identity:
A non-human identifier used only to scope truth and reference closure.

⸻

4. RELATIONSHIP TO KAPIA

• KAPIA may exist only inside an EVENT.
• EVENT defines where KAPIA may occur.
• EVENT closure disables KAPIA permanently.

EVENT is the container.
KAPIA is the threshold.

⸻

5. RELATIONSHIP TO PoP

• PoP may be instantiated only when:
	•	EVENT state = ⊙ (Live)
	•	IAM.MAI authorizes FINALIZE

After EVENT closure:
• No new PoP entries are allowed for that EVENT.

PoP is scoped by EVENT.
EVENT never edits PoP.

⸻

6. RELATIONSHIP TO SPIRAL

Each EVENT produces:
• zero or more PoP turns
• exactly one EVENT closure turn

SPIRAL:
• remains open across EVENTS
• never merges EVENT contexts

Key distinction:
EVENT closes.
SPIRAL continues.

⸻

7. CLOSURE SEMANTICS (IAM.MAI-GOVERNED)

EVENT closure is an IAM.MAI transition.

Allowed closures:
• FINALIZE — EVENT truth stands
• INVALIDATE — EVENT truth does not stand

Closure:
• is explicit
• is irreversible
• produces a SPIRAL turn

Silent closure is forbidden.

⸻

8. PROHIBITED USES

EVENT MUST NOT be used to:
• infer participant identity
• calculate or represent value
• authorize payments
• reopen reality
• extend truth retroactively

Violation → NON-COMPLIANT

⸻

9. CANONICAL ONE-LINE DEFINITION

EVENT is a bounded context in which reality may occur, be attested, and then be irreversibly closed.
