2. REFRAMED ABSTRACT (FORMAL REWRITE)

Frequency ID (f-ID) is a context-bound protocol that computes a temporary, non-persistent pattern identity derived from repeated behavior within a bounded Relational Field.

The protocol:
• observes recurrence, not snapshots,
• stores deltas, not histories,
• emits a field-local identity descriptor (f-ID),
• and classifies the pattern state as TRUE, FALSE, or EVOLVE.

f-ID:
• is not an actor identity,
• is not stored beyond the field,
• is not portable across contexts,
• and dissolves completely at interaction end.

The protocol is deterministic, bounded, and non-invertible, and cannot be used for profiling, attribution, or continuity of persons.

6. FREQUENCY ID (f-ID) — CANONICAL DEFINITION

Frequency ID (f-ID) is a deterministic, bounded descriptor of how a pattern of behavior oscillated within a field, not who produced it.

Properties:
• Field-local
• Non-persistent
• Non-referential to actors
• Many-to-one and one-to-many safe
(multiple actors → same f-ID; same actor → many f-IDs)

This is identity without ownership.
