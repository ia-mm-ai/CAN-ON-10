# MAI Canon

This repository contains the **canonical protocol specifications** used by IAMMAI-aligned systems.

These documents define:
- how irreversible transitions are legitimized,
- how presence becomes truth,
- how events are activated and closed,
- how memory and governance remain immutable and auditable.

## Scope

This repository is **normative**.

It specifies protocols such as:
- IAM.MAI (Transition Legitimacy)
- EVENT / EVENT-LIVE
- KAPIA
- PoP
- SPIRAL
- THIRD SPACE
- ROLE-ASSIGN
- SCHEMA

It does **not** contain:
- implementations
- user interfaces
- identity systems
- economic execution code

## Structure

- `/docs` — canonical protocol specifications  
- `/ledger` — immutable reference records (examples, non-executing)  
- `/third-space` — governance decision traces (non-authoritative)  

## Authority

This repository defines **rules**, not behavior.

Execution, enforcement, and interpretation occur **outside** this repo.
Nothing here performs actions or makes decisions.

## Status

Stable. Closed to additive change except via explicit evolution.
